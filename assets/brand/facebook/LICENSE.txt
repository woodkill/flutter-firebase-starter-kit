  채택 차원:
    - Form: Primary (파란 #1877F2 원형 배경 + 흰 'f') 단독 채택
    - Theme: 미분기 (D-94 Kakao 패턴, FacebookSpec theme 필드 부재)
    - Locale: 미분기 (D-96 Google 패턴, locale 독립 — Facebook 'f' 마크는
              언어 중립 — Roboto/Helvetica Latin 라벨 baked-in 아님)
    - Format: PNG only (D-95 = AssetType.png — Meta 의 logo pack 은 AI + PNG
              제공, SVG 미제공이라 PNG 채택)
  미포함 variant:
    - Secondary Logo (흰 원형 배경 + 검정 'f') — 모노크롬 인쇄/단색 환경 전용
      이라 Flutter mobile 컬러 환경에서는 Primary 단독으로 충분. Theme.dark
      에서도 Primary 의 #1877F2 배경이 가시성 보장 (1dp grey outline + white
      bg 패턴으로 dark theme 대응, D-93 fallback path D-94 채택과 일관).
    - AI 원본 파일 (Facebook_Logo_Primary.ai 164217 bytes) — Flutter 가
      Image.asset 로 PNG 직접 로드, AI 직접 사용 불가이므로 미동봉.
    - Login Button baked-in 자상 (예: "Continue with Facebook" 라벨 포함 PNG)
      — Meta 가 developers.facebook.com/docs/facebook-login/web/login-button
      에서 JS SDK 동적 위젯 (`data-button-type="continue_with"`) + 사이즈
      매트릭스 (Small 20×200 / Medium 28×200-320 / Large 40×240-400) 만
      명시. Flutter mobile 환경에서 JS SDK 위젯 임베드 불가 → starter-kit
      이 Apple `SignInWithAppleButton` 패턴 mirror 로 자체 render
      (Image.asset 18×18 + Text(authFacebookSignIn ARB) Row 조합, Plan
      13.2-04 의 `_renderFacebookButton` 함수).
